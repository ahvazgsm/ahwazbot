# AhwazBot

مخزن پروژه: https://github.com/ahvazgsm/ahwazbot

## نصب روی هاست cPanel

1. در cPanel یک دیتابیس MySQL و کاربر بسازید و دسترسی کامل کاربر به دیتابیس را بدهید.
2. نسخه PHP موردنیاز پروژه را از روی کد/هاست بررسی کنید. معمولاً افزونه‌های `mysqli`, `pdo_mysql`, `curl`, `mbstring`, `json`, `openssl`, `fileinfo`, `gd` و `zip` لازم می‌شوند.
3. ZIP را در `public_html` یا یک زیرپوشه آپلود و Extract کنید.
4. دامنه یا زیردامنه را به همان پوشه متصل کنید و HTTPS را فعال کنید.
5. به `https://YOUR-DOMAIN/installer/` بروید و اطلاعات دیتابیس، توکن ربات، شناسه مدیر و دامنه را وارد کنید.
6. پس از نصب موفق، دسترسی عمومی به پوشه `installer` را ببندید یا آن را حذف کنید؛ ابتدا مطمئن شوید نصب کامل شده و دیگر به آن نیاز ندارید.
7. در تلگرام `/start` را آزمایش کنید و گزارش خطا را بدون انتشار اطلاعات حساس بررسی کنید.

**مهم:** فایل `config.php` این بسته فقط نمونه است. اطلاعات واقعی را از طریق نصب‌کننده یا فایل پیکربندی خصوصی سرور وارد کنید. توکن ربات و رمز دیتابیس را در GitHub قرار ندهید.

## نصب روی سرور Ubuntu/Debian

> اسکریپت نصب دسترسی root می‌خواهد و ممکن است سرویس‌ها و فایل‌های سیستم را تغییر دهد. پیش از اجرا، اسکریپت را بازبینی کنید و روی سرور عملیاتی بدون بکاپ اجرا نکنید.

```bash
sudo apt update
sudo apt install -y ca-certificates curl git unzip
cd /opt
sudo git clone https://github.com/ahvazgsm/ahwazbot.git
cd ahwazbot
less install.sh
sudo bash install.sh
```

اگر مخزن خصوصی است، ابتدا دسترسی Git را تنظیم کنید. اگر نصب‌کننده نسخه‌ای از فایل‌ها را از مخزن دیگری دریافت می‌کند، آن آدرس‌ها را پیش از استفاده بررسی کنید؛ انتشار این مخزن به‌تنهایی تضمین نمی‌کند همه URLهای داخلی اسکریپت به مخزن جدید منتقل شده باشند.

## امنیت پیش از انتشار

- فقط از توکن‌های جدید و مختص ربات خود استفاده کنید؛ هر توکنی که قبلاً در فایل‌های منتشرشده یا لاگ‌ها بوده باید از BotFather باطل و تعویض شود.
- هیچ‌وقت `config.php` واقعی، فایل‌های `.env`, لاگ‌ها، بکاپ دیتابیس، اطلاعات کاربران یا فایل‌های runtime را commit نکنید.
- برای نصب‌کننده و پنل مدیریتی HTTPS و دسترسی محدود تنظیم کنید.
- قبل از به‌روزرسانی، از فایل‌ها و دیتابیس نسخه پشتیبان بگیرید.

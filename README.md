## 🌟 درباره پروژه

**AhwazBot** مخزن پروژه‌ای برای توسعه و مدیریت ربات تلگرام است که با هدف ساده‌تر کردن راه‌اندازی، پیکربندی و نگهداری سرویس‌ها ارائه می‌شود.

- 🖥️ اسکریپت نصب برای سرور، در صورت سازگاری با سیستم‌عامل
- 🤖 زیرساخت ربات تلگرام
- ⚙️ ابزارهای پیکربندی و مدیریت پروژه
- 🔧 امکان توسعه و شخصی‌سازی سورس
- 🔐 تأکید بر نگهداری امن اطلاعات محرمانه

> قابلیت‌های واقعی به سورس موجود و نسخه‌ای که نصب می‌کنید بستگی دارد.

## 🧰 پیش‌نیازها

پیش از نصب، موارد زیر را بررسی کنید:

- دسترسی لازم به سرور یا هاست
- اتصال شبکه به GitHub
- سازگاری نسخه PHP و افزونه‌های موردنیاز
- اطلاعات دیتابیس و تنظیمات ربات، در صورت نیاز
- تهیه نسخه پشتیبان از اطلاعات موجود

## 🚀 نصب روی Ubuntu و Debian

ابتدا فایل نصب را دریافت کنید:

```bash
sudo apt update
sudo apt install -y curl
curl -fL https://raw.githubusercontent.com/ahvazgsm/ahwazbot/main/install.sh -o /root/install.sh
```


**توجه:** دانلود موفق فایل به معنی موفقیت نصب نیست. سازگاری نسخه PHP، مخازن سیستم‌عامل، سرویس‌ها و مسیرهای نصب باید بررسی شود.

## 🌐 نصب روی cPanel

1. فایل‌های پروژه را در پوشه موردنظر بارگذاری و استخراج کنید.
2. دیتابیس MySQL و کاربر آن را ایجاد کنید.
3. نسخه PHP و افزونه‌های موردنیاز را مطابق سورس بررسی کنید.
4. تنظیمات اتصال دیتابیس و ربات را تکمیل کنید.
5. HTTPS را فعال کنید.
6. پس از نصب، مسیرهای نصب و فایل‌های حساس را از دسترسی عمومی محافظت کنید.

آدرس و روش دقیق نصب وب باید با ساختار واقعی فایل‌های مخزن مطابقت داشته باشد.

## 🔄 به‌روزرسانی

قبل از به‌روزرسانی:

1. از فایل‌ها و دیتابیس نسخه پشتیبان تهیه کنید.
2. تغییرات نسخه جدید را بررسی کنید.
3. تنظیمات و فایل‌های محلی را حفظ کنید.
4. سازگاری نسخه جدید را در محیط آزمایشی بررسی کنید.
5. پس از به‌روزرسانی، عملکرد ربات و گزارش خطاها را آزمایش کنید.

## 🔐 امنیت

- توکن ربات تلگرام و رمز دیتابیس را منتشر نکنید.
- فایل‌های `.env`، تنظیمات واقعی، بکاپ‌ها و اطلاعات کاربران را در مخزن عمومی قرار ندهید.
- در صورت افشای توکن یا رمز، آن را فوراً تعویض کنید.
- اسکریپت‌های نصب را پیش از اجرای دستورات مدیریتی بررسی کنید.
- برای پنل وب از HTTPS و کنترل دسترسی مناسب استفاده کنید.
- از اطلاعات مهم نسخه پشتیبان تهیه کنید.

## 🐛 گزارش مشکل

برای گزارش خطا، اطلاعات زیر را همراه گزارش ارسال کنید:

- نسخه سیستم‌عامل
- نسخه PHP یا ابزار مرتبط
- مرحله‌ای که خطا رخ داده است
- متن خطا بدون اطلاعات محرمانه

**هرگز توکن ربات، رمز عبور، کلید خصوصی یا اطلاعات کاربران را در گزارش عمومی قرار ندهید.**

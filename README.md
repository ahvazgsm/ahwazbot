## نصب روی هاست cPanel

1. در cPanel یک پایگاه داده MySQL و کاربر بسازید و مجوزهای لازم را به کاربر بدهید.
2. نسخه PHP سازگار با پروژه را بررسی کنید. افزونه‌های موردنیاز را از روی کد و تنظیمات هاست مشخص کنید؛ مواردی مانند `mysqli`، `pdo_mysql`، `curl`، `mbstring`، `json`، `openssl`، `fileinfo`، `gd` و `zip` ممکن است لازم باشند.
3. فایل ZIP پروژه را در `public_html` یا زیرپوشه موردنظر بارگذاری و استخراج کنید.
4. دامنه یا زیردامنه را به پوشه پروژه متصل و HTTPS را فعال کنید.
5. نصب‌کننده را باز کنید:

   ```text
   https://YOUR-DOMAIN/installer/
   ```

6. اطلاعات دیتابیس، توکن ربات، شناسه مدیر و سایر مقادیر موردنیاز نصب‌کننده را وارد کنید.
7. پس از اطمینان از نصب موفق، دسترسی عمومی به پوشه `installer` را محدود یا آن را حذف کنید.
8. در تلگرام فرمان `/start` را آزمایش کنید و گزارش خطاها را بدون انتشار اطلاعات حساس بررسی کنید.

**مهم:** پیش از استفاده، فایل `config.php` را بررسی کنید. اطلاعات واقعی و محرمانه را در GitHub قرار ندهید.

## نصب روی سرور Ubuntu/Debian

### پیش‌نیازها

- دسترسی مدیریتی به سرور
- اتصال شبکه به GitHub
- نصب بودن Git
- بررسی سازگاری اسکریپت نصب با سیستم‌عامل و سرویس‌های سرور

### نصب اولیه

اگر مخزن را از قبل در مسیر `/opt/ahwazbot` دریافت کرده‌اید و فایل `install.sh` در آن موجود است، دستور زیر را اجرا کنید:

```bash
sudo bash /opt/ahwazbot/install.sh
```

**توجه:** پیش از اجرا، محتوای اسکریپت را بررسی کنید. این دستور به‌تنهایی تضمین نمی‌کند که همه سرویس‌ها، دیتابیس یا وب‌سرور به‌صورت خودکار نصب و پیکربندی شوند.

## به‌روزرسانی پروژه

برای دریافت به‌روزرسانی‌های بعدی، ابتدا از دیتابیس و فایل‌های تنظیمات نسخه پشتیبان تهیه کنید. سپس اجرا کنید:

```bash
sudo bash /opt/ahwazbot/update.sh
```

### نکات مهم به‌روزرسانی

- پیش از اجرا، مطمئن شوید مسیر نصب صحیح است.
- تغییرات محلی پروژه را بررسی و ذخیره کنید.
- اگر مخزن خصوصی است، دسترسی Git را برای کاربری که فرمان را اجرا می‌کند تنظیم کنید.
- به‌روزرسانی سورس لزوماً شامل مهاجرت دیتابیس یا تغییر تنظیمات سرور نیست.
- در صورت بروز خطا، گزارش اسکریپت را بررسی کنید و اطلاعات محرمانه را منتشر نکنید.

## امنیت پیش از انتشار

- توکن ربات و رمز دیتابیس را محرمانه نگه دارید.
- فایل واقعی `config.php`، فایل‌های `.env`، لاگ‌ها، بکاپ دیتابیس و اطلاعات کاربران را در مخزن عمومی قرار ندهید.
- اگر توکن یا رمز عبوری قبلاً منتشر شده است، آن را تعویض کنید.
- برای دامنه از HTTPS استفاده کنید.
- قبل از اجرای اسکریپت‌های مدیریتی یا به‌روزرسانی، از فایل‌ها و دیتابیس نسخه پشتیبان بگیرید.
- آدرس‌های مخزن و منابع دانلود داخل اسکریپت‌ها را بررسی کنید تا از مخزن مورداعتماد دریافت شوند.
